Open windows

Tell Ninetails which window is which. It remembers this across restarts and labels each window's title bar, e.g. [Research] …. You can also do it from inside any window: click the Ninetails toolbar button → This Firefox window is, or right-click a tab → Ninetails → Make this window.

Behavior (saved per profile)

Never touched: pinned tabs, the tab showing in each window, tabs playing sound, and tabs you've dragged somewhere by hand.

Never touch

Pages matching these patterns are never moved, sorted into a category or closed as duplicates.

Auto-close

For throwaway pages like Zoom's “launch meeting” tabs. A matching tab closes once it's been open and unused for that long. Ninetails skips it while you're looking at it or while it's playing sound, and closed tabs show up under Closed tabs below. Zoom's in-browser meeting client (zoom.us/wc/…) isn't listed, so a meeting you join in Firefox won't be closed.
